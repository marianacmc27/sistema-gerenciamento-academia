## 📋 Descrição do Projeto
O **Sistema de Gerenciamento de Academia** é uma plataforma web desenvolvida para automatizar e centralizar os processos operacionais e financeiros de uma academia de ginástica. O software gerencia cadastros de alunos, controle de planos, pagamentos, registro de frequência na recepção e a programação de aulas em grupo com validação rigorosa de capacidade máxima e limite de vagas.

---

## ⚙️ Tecnologias Utilizadas (Stack do MVP)
* **Backend:** Python (FastAPI / Flask)
* **Banco de Dados:** PostgreSQL (Persistência relacional)
* **Segurança:** OAuth2 com JSON Web Tokens (JWT) e hash seguro com `bcrypt` (`passlib`)
* **Frontend:** HTML5, CSS3 e JavaScript (ES6+ com Fetch API)

## 🚀 Como Compilar e Executar o Sistema Localmente

Siga os passos abaixo para configurar e rodar o projeto em sua máquina local (ambiente Linux/Ubuntu recomendado):

### 1. Pré-requisitos
Certifique-se de ter instalado em seu computador:
* Python 3.10 ou superior
* Gerenciador de banco de dados PostgreSQL
* Git

### 2. Clonar o Repositório
Abra o terminal e execute o comando:
```bash
git clone [https://github.com/SEU-USUARIO/sistema-gerenciamento-academia.git](https://github.com/SEU-USUARIO/sistema-gerenciamento-academia.git)
