## Sobre o Projeto
Este repositório contém a implementação do MVP (Minimum Viable Product) do Sistema de Gerenciamento de Academia, desenvolvido com base na especificação de requisitos e modelagem dos Labs 1 a 5. O sistema contempla autenticação por perfis (Administrador e Aluno), controle de turmas com limite de vagas, gestão de cadastros, planos e situação financeira.

## Tecnologias Utilizadas
- **Backend:** Python, FastAPI, SQLAlchemy, SQLite
- **Frontend:** HTML5, CSS3 moderno, JavaScript (Fetch API)
- **Servidor ASGI:** Uvicorn
